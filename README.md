LR2HD Timing Adjuster v1.0
LR2HD Timing Adjuster is a specialized external utility designed for Lunatic Rave 2 (LR2HD).

It allows players to adjust judgment timing in real-time using customizable hotkeys (e.g., NumPad), providing a smooth experience for fine-tuning your gameplay.

[English]
✨ Key Features
Real-time Adjustment: Modify your timing offset (TIMING) instantly during gameplay.

Hotkey Support: Assign keys for timing up/down and preset switching via NumPad or other keyboard inputs.

Visual Status: Clear indication of connection status (Connected/Disconnected) and Process ID (PID).

Preset Management: Save and switch between multiple timing presets instantly to suit different conditions.

Safe Execution: Operates as an independent external process without modifying original game files.

🚀 Development Background
In the original game, player timing adjustments could only be made on specific screens (e.g., music select), requiring tedious mouse clicking. This tool solves that frustration by allowing one-touch adjustments.

This project is a unique collaboration between an amateur enthusiast and Gemini (Google AI). As it was built through AI-assisted programming by someone without professional coding knowledge, we focused on creating a practical, user-friendly solution.

📖 How to Use
Create a folder (e.g., LR2HD Timing Adjuster) inside your LR2 main directory.

Place LR2HD Timing Adjuster v1.0.exe in that folder.

Launch LR2HD.

Run the tool as Administrator.

config.json will be generated automatically on the first launch.

Configure your keys in the GUI and click "Save Config".
